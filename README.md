# 🚀 NFT Marketplace UI (Front-end)

Bu layihə müasir və responsiv bir NFT bazar platformasının ön tərəf (front-end) hissəsidir. Layihə dizayn və funksionallığı birləşdirərək istifadəçilərə rahat təcrübə təqdim edir.

## ✨ Xüsusiyyətlər
- **Gözoxşayan Dizayn:** Qaranlıq mövzu (dark mode) və NFT dünyasına uyğun vizuallar.
- **Çoxsəhifəli Struktur:** Ana səhifə, Log In, Sign Up və yaradıcıların reytinq cədvəli.
- **Responsivlik:** Mobil və masaüstü cihazlar üçün tam uyğunluq.

## 🛠 Texnologiyalar
- **HTML5:** Semantik strukturun qurulması üçün.
- **CSS3:** Flexbox, Grid və xüsusi animasiyalar üçün.
- **JavaScript:** Səhifələrarası keçid və interaktiv elementlər üçün.
